# Privacidad

El servicio envía el texto de la consulta a Codex. Una consulta visual adjunta
cuatro imágenes por fuente solicitada. Las vistas previas se borran en breve
del directorio privado de sesión. El socket, los datos y el SVG de la última
gráfica son locales. Las fuentes del RAG se comparten mediante extractos.
Mantén fuera de Git el historial, las grabaciones, los modelos y las credenciales.
