# Quickstart

1. Run `./free-hands doctor` and confirm Codex, Handy, and notifications are
   available.
2. Start `free-hands.service`.
3. Hold Alt+Z, speak, and release.
4. DOOM sends the request to the active Codex thread and reads the response.
5. Say “new chat” or use `free-hands chat-new "topic"` to start a thread.

Use `free-hands status`, `free-hands cancel`, and `free-hands chat-search WORD`
for the common controls.
